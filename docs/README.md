# Docs

- `accessibility/ACCESSIBILITY.md`, `MANUAL_TESTS.md`, `BRAILLE.md`, `BRAILLE_TEST_PROTOCOL.md`, `LICENCES.md`: how Bloop works with screen readers and braille, how to test it by hand, the licences of what it uses.
- `official/`: one method doc per Official record (written by the pipeline), and `VALIDATION_TABLE.md`, every record's checks.
- `related/`: one doc per Related record and the candidate lists (written by the pipeline).
- `data-integration-status.md`: which datasets are in the app and how each is checked.
- `THEN_VS_NOW_STATS.md`: the statistics behind Then vs Now.
- `LISTEN_TEST_PROTOCOL.md`: the listener test.
- `audio/MIX.md`: loudness and the mix; `audio/mix_*.json` are its measurements.
- `cvml/BUILD.md`: the value chord and what the jukebox reads (linked from the app).
- `HEALTH.md`, `FEATURES_WORKING.md`: record health and feature checks (written by `npm run health`).
- `i18n/TO_TRANSLATE.md`: Bangla strings waiting for a check (generated).
- `voice/GATE_TEST.md`, `voice/benchmark.json`: Ask Bloop's speech gate test and parser benchmark.
- `turntable.md`: the Turntable's assets, their licences and credits.
- `official_resources_links.md`: the NASA pages the resource watch checks.
- `MENTOR_FIXES.md`, `TEAM_BUILD_PLAN.md`, `L2/BUILD_PLAN.md`: cited by tests and data as sources.
- `readme/`: images in the top-level README.
