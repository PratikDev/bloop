# Sonification precedents (method evidence, not data)

Generated by `pipeline/svs/precedents.py`. Quotes are verbatim from each page; no audio is downloaded or redistributed. Bloop's grammar: a value sets pitch (equal steps sound equal), the reading moves in time or under a needle, one voice per variable, silence where there is no data, model and observation in different timbre families.
